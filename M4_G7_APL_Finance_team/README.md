# M4 – G7 APL Finance Team

## Project
Portfolio Temporal Structure Learning with Dynamic Bayesian Networks

## Milestone 4 – Final Submission

This folder contains the final project code, datasets, experimental results, technical report, presentation, and demonstration video.

## Folder Structure

- `Code/` – Python source code, dependencies, and code documentation.
- `Data/` – Input datasets used for the experiments.
- `Results/` – Model outputs, experimental results, figures, and evaluation metrics.
- `Report/` – Final project technical report.
- `Presentation/` – Final project presentation slides.
- `Video/` – Final project demonstration video.

## Requirements

Install the required dependencies using:

```bash
pip install -r Code/requirements.txt
```

## Execution

Run the project from the appropriate working directory using:

```bash
python Code/src/run_all.py
```
